# My Budget Tracker

## Project Description

My Budget Tracker is a simple web page designed to help users record and review their expenses. It displays sample expenses in a table and provides a form for entering expense details.

This project was developed as part of the PLP Week 2 Web Development Assignment, building on the Week 1 Budget Tracker project.

## Project Files

### 1. index.html

The `index.html` file contains the structure and content of the web page. It includes:

- A main heading with a budget tracker logo.
- An Add Expense form with fields for expense name, amount, and category.
- A category dropdown containing Food, Transport, Rent, Entertainment, and Other.
- An expense table with four columns: Name, Amount, Category, and Date.
- Five sample expense records.
- An embedded YouTube video about budgeting tips.
- A collapsible help section explaining how to use the tracker.

### 2. style.css

The `style.css` file controls the appearance of the web page. It includes:

- Background colours, spacing, borders, and rounded corners.
- Styling for the Add Expense form, inputs, dropdown, and button.
- Table borders, cell padding, a blue header, and alternating row colours.
- Hover effects for table rows and the Add Expense button.
- Focus styling for form inputs.
- Advanced CSS selectors, including descendant selectors, the `:not()` pseudo-class, `:focus`, `:nth-child(even)`, and `:hover`.

## Technologies Used

- HTML5
- CSS3

## How to Run the Project

1. Download or clone the project repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. View the expense table, form, video, and help section.

An internet connection is required to load the externally hosted logo and YouTube video.

## Current Limitations

The Add Expense button is not yet connected to JavaScript, so submitting the form does not add new records to the table. The table currently displays hardcoded sample expenses.

## Learning Outcomes

Through this project, I practised creating HTML tables and forms, embedding multimedia, using interactive HTML elements, and applying advanced CSS selectors.
