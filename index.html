How to use this Budget Tracker

Follow these steps to use your Budget Tracker:

  1. Enter the name of your expense.
  2. Enter the amount spent in Kenyan Shillings (KSh).
  3. Select the correct expense category.
  4. Click the Add Expense button.
  5. Review the expense records in the table below.

Note: The Add Expense button is not functional yet. We will add that functionality when we learn JavaScript.
